Processo simples

Da solicitação à entrega.

PASSO 01

Pedido

O cliente fornece os dados de recolha e destino.

PASSO 02

Registo

A equipa atribui uma referência única após confirmar o pedido.

PASSO 03

Distribuição

A encomenda é encaminhada para um estafeta.

PASSO 04

Confirmação

O estado é actualizado manualmente após verificação.

Novo pedido

Solicitar uma entrega

Preenche os campos para preparar uma mensagem. Nesta versão, o pedido não é enviado nem guardado automaticamente.

Não introduzas senhas nem dados bancários. O formulário não envia nem guarda dados.

Antes de confirmar

O que acontece a seguir?

A equipa deverá confirmar disponibilidade, preço e horário antes de aceitar o serviço.

  • Verificar endereço e contacto.
  • Confirmar o preço antes da recolha.
  • Atribuir referência pela equipa.
  • Registar o pagamento conforme o método acordado.
Demonstração: o formulário prepara texto para copiar. Ainda não existe base de dados nem envio automático.
Consulta manual

Consultar uma referência

Introduz a referência recebida da equipa. Esta versão não consulta registos reais, pois ainda não está ligada a uma base de dados.
