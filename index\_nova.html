Novo pedido

O que precisas de enviar?

Preenche os dados para preparar o teu pedido. Nesta demonstração, os dados ficam apenas no teu navegador e não são enviados para a empresa.

Não introduzas senhas nem dados bancários. Ainda não existe envio automático nem registo permanente.

Antes da confirmação

Como funciona

A equipa confirma a disponibilidade, o preço e o horário antes de aceitar a entrega.

  1. Indica a recolha e o destino.
  2. Aguarda confirmação da equipa.
  3. Recebe uma referência quando o pedido for registado.
  4. Acompanha o estado após a activação do rastreio real.
Esta é a nova interface visual. Para guardar encomendas e permitir acesso privado, será necessário ligar uma base de dados e configurar autenticação.
